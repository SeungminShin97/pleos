# 차량 휴식 모드 기획

점심 휴식, 졸음쉼터, 명상, 차박은 후속 개발 범위다.

각 모드는 사용자에게 맞춘 시트 설정과 휴식 루틴을 연결한다. 사용자는 시트를 한 번 맞춰 저장한 뒤 모드에서 선택한다. 같은 시트 설정을 여러 모드에서 사용할 수 있다. 시간과 알람 대상은 시작 전에 확인하고 바꿀 수 있다.

| 모드 | 사용 상황 | 기본 루틴 | 종료 |
| --- | --- | --- | --- |
| 점심 휴식 | 점심시간에 주차한 차에서 휴식 | 1시간 휴식 알람. 차량과 휴대폰 알람은 각각 선택 | 알람 후 사용자가 휴식을 끝낸다 |
| 졸음쉼터 | 장거리 주행 중 가까운 곳에 들러 짧게 휴식 | 현재 위치와 주행 방향을 기준으로 쉼터 검색. 정차 상태에서 기본 내비 목적지 또는 경유지 설정. 도착 후 20분 휴식 알람 | 알람 후 운전자가 상태를 확인하고 이동을 이어간다 |
| 명상 | 주차한 차에서 잠깐 집중하거나 쉬는 시간 | 10분 타이머와 선택한 음악 | 타이머가 끝나면 음악을 멈추고 종료를 알린다 |
| 차박 | 주차한 차에서 장시간 휴식 | 배터리 감시, 공조 상태 확인, 선택 기상 알람 | 사용자가 휴식을 끝내면 모드에서 시작한 배터리 감시를 종료한다 |

졸음쉼터와 명상의 시간은 변경 가능한 제안값이다. 이미 쉼터에 주차한 사용자는 장소 검색을 건너뛰고 바로 알람을 설정할 수 있다. 경유지로 추가할 경우 기존 목적지를 유지한다.

## 시작과 종료

모드를 고르면 연결된 시트 설정과 루틴을 보여준다. P단과 정차 상태를 확인한 뒤 사용자가 시작한다. 시트 적용을 확인할 수 없는 차량 환경에서는 사용자가 직접 조정할 수 있게 안내한다. 알람과 타이머는 휴식이 끝날 시간을 알린다. 사용자가 “시트 원래대로 돌려줘”라고 요청하면 P단과 정차 상태를 다시 확인한 뒤 휴식 전 시트 위치로 복귀하는 것이 목표다. 차량용 저장 위치 재현과 음성 복귀는 추가 검증이 필요하다.

휴대폰 연동과 휴대폰 알람 옵션을 켠 사용자는 차량에서 알람을 한 번 설정하면 같은 시각을 휴대폰 기본 시계에도 자동으로 등록하는 것이 목표다. 현재 구현은 Bluetooth로 시각을 보내고 휴대폰에서 기본 시계 등록을 확인하는 단계까지 검증했다. 차박의 장시간 전원과 공조 유지는 지원 차종과 Pleos API를 검증한 뒤 지원 범위를 결정한다.

## 저장 구조

모드 테이블 하나에 모드 종류와 이름, 기존 휴식 설정 ID, 루틴 옵션을 저장하는 구상이다. 시간 또는 기상 시각, 알람 대상, 음악, 배터리 감시 같은 정해진 옵션을 사용한다. 실행에 사용한 옵션은 기존 휴식 세션에 기록해 모드 설정을 바꿔도 진행 중인 루틴의 기준을 유지한다.
